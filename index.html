⚡ Java Tree Indexing Architecture

All indexing models correspond to authentic Java classes: tree.BST (unbalanced binary tree), tree.AVLTree (rotations LL, RR, LR, RL), tree.BTree (multiway branching, order $t=3$), and tree.BPlusTree (sequential leaf pointers).
Note on B+ Tree: The original Java BPlusTree.java utilized a simplified single-node structure (insertSimple without node splitting). The frontend implementation incorporates full B+ Tree splitting with index router nodes and sequential leaf pointers ($t=3$) for educational visualization.
